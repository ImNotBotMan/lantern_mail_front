# Город профиля и путь письма

## Responsibility

**Ответственность:** справочник городов, выбор и смена города в профиле и показ пути письма.
Экраны и компоненты модуля:

- **`pages/CityPage.tsx`** — шаг выбора города после регистрации и для пользователя без города:
  форма с `CityPicker`, отправка `PATCH /users/me`, затем переход во входящие.
- **`features/city/CityPicker.tsx`** — справочник целиком списком радиокнопок: названия на двух
  языках и страна, состояния загрузки и ошибки с повтором.
- **`useCities()`** — запрос справочника через TanStack Query.
- **`cityName` / `countryName`** — выбор колонки названия по языку интерфейса.
- **`AccountPage`** — секция «Ваш город»: текущий город, действие «Изменить», inline-форма
  смены и строка недельного лимита.
- **`features/letters/CityPath.tsx`** — строка пути на конверте и на письме; компонент живёт
  в модуле писем, но название города берёт здесь.

## Boundary

- Разрешено: `module-front-api-client` (`citiesApi`, `usersApi`), `module-front-session`
  (`updateUser` — обновить профиль в открытой сессии), `shared/i18n`, `shared/ui`, роутер.
- Запрещено: считать задержку доставки, проверять право на смену города, склонять названия
  городов по падежам, читать справочник напрямую в других модулях (только через `cityName` и
  `useCities`).

## Ключевые правила

- **Город обязателен для продукта.** Без города `CityRequired` уводит на `/city` (см.
  `module-front-session`); тот же запрет держит сервер — `send` отвечает
  `sender_city_missing` / `recipient_city_missing`, и клиент показывает перевод кода, а не
  свою проверку.
- **Решение о смене — за сервером.** Клиент из `city_changed_at` (плюс 7 суток) только решает,
  что показать: кнопку «Изменить» или дату, с которой смена доступна. Момент сравнивается один
  раз при открытии экрана, а не на каждом рендере. Ответ `city_change_too_soon` всё равно
  показывается ошибкой — сервер остаётся источником правды.
- **Справочник — одна колонка на язык.** Названия городов не переводятся словарями: сервер
  отдаёт `name_ru`/`name_en` и `country_ru`/`country_en`, клиент выбирает нужную. Поэтому
  строка пути печатается без предлогов («Москва → Санкт-Петербург»): в именительном падеже
  названия из справочника согласовать с «из/в» нельзя.
- **Справочник кэшируется.** Ключ `['cities']`, `staleTime` 5 минут: города меняются только
  миграцией бэкенда, а после выбора города справочник не инвалидируется.
- **Путь — только снимок письма.** `CityPath` рисует `sender_city`/`recipient_city` из ответа и
  молчит, если их нет (черновик, запечатанное, письма до появления городов). Путь летящего
  письма не зависит от текущего профиля.
- **Список без поиска и пагинации.** Городов десятки — список показывается целиком, с прокруткой;
  отдельного экрана каталога нет: `/city` — шаг, а смена живёт в профиле.

## Пользователь видит

- `/city` — отдельный layout входа: заголовок «Выберите город», подсказка про путь письма и
  недельный лимит, список городов, «Сохранить» (неактивна без выбора).
- После сохранения — входящие; ошибка (`city_change_too_soon`, `city_not_found`, сеть)
  показывается над формой и оставляет пользователя на экране.
- `/account` — «Ваш город» с названием текущего города; «Изменить» открывает тот же список
  inline; пока лимит не истёк — «Город можно изменить с <дата>».
- Конверт и письмо — строка пути под отправителем: «Москва → Санкт-Петербург».

## Проверки

MSW-тесты: справочник показывается на языке интерфейса; «Сохранить» неактивна без города;
выбранный город уходит `PATCH` с `city_id` и открывает входящие; отказ `city_change_too_soon`
показывается ошибкой и оставляет на шаге; пользователя без города guard уводит с `/inbox`;
профиль показывает город и меняет его; при действующем лимите вместо кнопки — дата; `CityPath`
называет города и молчит без снимка.

E2E на живом бэкенде (`e2e/city.spec.ts`, `e2e/auth.spec.ts`, `e2e/letters.spec.ts`):
регистрация ведёт на шаг выбора города и только потом в приложение; прямой `/inbox` без города
не обходится; после выбора города профиль показывает его и дату смены; письмо между разными
городами показывает путь на конверте. Пользователи в e2e создаются через API с городом по
умолчанию, а `createUser(..., null)` оставляет пользователя без города для проверки шага.
