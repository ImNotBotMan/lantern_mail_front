# Локализация и UI-примитивы

## Responsibility

**Ответственность:** два сквозных слоя, на которых стоят все экраны — тексты на двух языках
и базовые визуальные примитивы с токенами оформления.

## Boundary

- Разрешено: `i18next`, `react-i18next`, `Intl`, CSS.
- Запрещено: знать про письма, друзей и сессии; обращаться к сети; хранить прикладные данные.
  Модуль не решает, что показать, — он даёт кнопку, поле, бейдж, заголовок и текст по ключу.

## Языки

- Русский и английский. Язык по умолчанию — из браузера (`navigator.language`), при отсутствии
  поддержки — `ru`. Выбор пользователя сохраняется в `localStorage` и переживает перезагрузку.
- Переключатель языка доступен с экрана входа (до авторизации) и в шапке приложения.
- Переключение мгновенное, без перезагрузки; текущий адрес сохраняется.

## Ключи и словари

- Словари — `src/shared/i18n/ru.json` и `en.json`, плоские ключи вида
  `область.экран.элемент` (`letters.inbox.empty`, `errors.not_friends`, `common.retry`).
- Ни одной строки в разметке: текст берётся только по ключу. Строки не склеиваются конкатенацией —
  порядок слов в английском и русском разный, поэтому подстановки идут через интерполяцию
  i18next.
- Множественное число — через плюральные формы i18next (`letters.inbox.count`), а не через
  условные выражения в коде.
- Даты и время — `Intl.DateTimeFormat` с текущей локалью; формат дат не собирается руками.

## Ошибки API

- Для каждого кода из `module-backend-contract` есть ключ `errors.<code>`.
- Если перевода для кода нет — показывается `message` от сервера: контракт может вырасти
  раньше словарей, и пользователь не должен увидеть технический код.
- Отдельный ключ `errors.network_error` — «нет связи», с кнопкой повтора.

## UI-примитивы

Кнопка, поле с подписью и текстом ошибки, бейдж статуса, модалка подтверждения, индикатор
загрузки, пустое состояние, состояние ошибки, шапка и layout.

- Оформление — CSS-переменные (цвета, типографика, отступы) плюс CSS-модули; рантайм-CSS-in-JS
  не используется.
- Цвет — не единственный носитель смысла: статус письма это текст плюс бейдж, а не только
  оттенок.
- Модалка и меню закрываются по `Esc`, фокус переходит внутрь и возвращается обратно;
  интерактивные элементы доступны с клавиатуры и имеют видимый фокус.
- Тема одна — светлая. Тёмная тема и настройки вида — не в этой версии. *(Выведено из состава
  первого билда; не подтверждено.)*

## Проверки

Тесты: каждый ключ существует в обоих словарях (проверка равенства наборов ключей в CI);
переключение языка меняет текст без перезагрузки и сохраняется; неизвестный код ошибки
показывает `message` сервера; модалка закрывается по `Esc`.
