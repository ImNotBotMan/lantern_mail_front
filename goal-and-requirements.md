# Lantern Mail Front — цель и требования

Веб-клиент «медленной почты» Lantern Mail. Продукт и его цель описаны в спеке-графе
бэкенда: `../docs/specs/goal-and-requirements.md` (id `lantern-mail`), процессные правила —
в [конституции](../docs/constitution.md).

## Обзор

Веб-клиент для существующего Lantern Mail: письмо пишут, запечатывают и отправляют, а
получатель видит, что оно «летит» к нему, но прочитать может только после доставки.
Сегодня продуктом можно пользоваться только через мобильное приложение — веб-клиент
даёт тот же продукт в браузере на десктопе. Замысел продукта — личная переписка,
развиваемая в настоящий продукт и одновременно служащая use-case для портфолио.

## Возможности

Первый полезный билд (решено с пользователем):

- **Аккаунты.** Регистрация (email, `username`, пароль), вход, выход. Сессия живёт на
  паре токенов бэкенда (access 15 мин + refresh 30 дней): клиент молча обновляет пару
  через `/auth/refresh`, при истечении/отзыве возвращает на вход.
- **Письма — полный цикл.** Написать и отредактировать черновик, запечатать
  (открытка, печать, марка), распечатать, отправить, прочитать, удалить (DRAFT/SEALED).
  Входящие: письмо в пути видно как конверт (отправитель и обёртка, без текста и времени
  доставки); после доставки — всё. Статусы письма клиент вычисляет из дат
  (`sealed_at`/`sent_at`/`deliver_at`/`read_at`), как это делает бэкенд — никакого
  опроса «статуса» в API не существует. Отменённые письма получатель не видит (404).
- **Друзья.** Поиск пользователей по подстроке `username`, заявки в друзья
  (отправить, принять, отклонить, отменить), список друзей, удаление из друзей.
  Письмо можно отправить только взаимному другу или самому себе.
- **Языки интерфейса.** Русский и английский с первого дня (i18n).

## Технические заметки

- React + Vite + TypeScript, SPA. *(Подтверждено пользователем.)*
- API-контракт: OpenAPI из FastAPI (`/docs`), единый формат ошибок
  `{ "error": "<код>", "message": "..." }`.
- Для запросов из браузера бэкенду понадобится CORS — сейчас он не настроен
  (отмечено в SUMMARY бэкенда как «не сделано»).
